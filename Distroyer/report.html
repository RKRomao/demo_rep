#001 HIGH Missing Security Header: Strict-Transport-Security headers ⌄
Severity
HIGH
CVSS Score
5.3 / 10.0
OWASP Category
A05:2021 - Security Misconfiguration
CWE Reference
CWE-1021
Summary
The Strict-Transport-Security header is not set.
What is this vulnerability?
One or more standard HTTP security response headers are absent from the server responses. Modern browsers rely on these headers to activate built-in security defenses (such as anti-clickjacking, MIME-type enforcement, and secure referrer handling).
Business & Technical Impact
Heightens vulnerability to clickjacking, client-side MIME-sniffing attacks, cross-origin data leaks, and proxy caching of sensitive user data.
Technical Evidence / Proof of Concept
— No specific evidence captured —
  • 1Configure all recommended security headers on web servers or reverse proxies:
  • 2Strict-Transport-Security: max-age=31536000; includeSubDomains; preload
  • 3Content-Security-Policy: default-src 'self'; frame-ancestors 'self';
  • 4X-Content-Type-Options: nosniff
  • 5X-Frame-Options: SAMEORIGIN
  • 6Referrer-Policy: strict-origin-when-cross-origin
  • 7Permissions-Policy: geolocation=(), camera=(), microphone=()
  • 8Cache-Control: no-store (on sensitive authenticated routes)
